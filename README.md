# ⏱️ [Bomb Clicker]

**[Bomb Clicker]** — это динамичный аркадный кликер, где твоя главная задача — проверить скорость своей реакции и набрать как можно больше очков за ограниченное время.

### 🎮 Особенности игры:
* **Игра против времени:** Каждый клик приближает тебя к рекорду, но таймер неумолимо идет к нулю.
* **Простая и затягивающая механика:** Легко начать, сложно оторваться!
* **Брось вызов себе:** Улучшай свой результат с каждой новой попыткой.

### 🚀 Как играть:
1. Нажимай на бомбу и получай монеты чтобы потом восполнить время чтобы потом бомбу обезвредить.
2. Кликай как можно быстрее, чтобы накапливать очки.
3. Постарайся достигнуть самой сложной бомбы, до того как истечет время!
